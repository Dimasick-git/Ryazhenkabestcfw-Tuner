Ryazhenkabestcfw Tuner — Release Notes

Проект относится к прошивке Ryazhenka:
https://github.com/Dimasick-git/Ryazhenka_Bot

Изменения и исправления:

- Исправлена настройка CPU vMin High: поправлены битые hex-значения, из-за которых ломалось применение «Мин. напр / смещение».

- GPU: исправлена/синхронизирована настройка «Мин. напр. → Макс. смещ.» (GPU DVFS Offset):
  - приведены к одному названию пункта конфиги UI и восстановление индекса;
  - теперь корректно сохраняется/восстанавливается значение (index) из sys-clk/Ryazha-clk (gpu_vmin_offset).

- Updater: удалён устаревший файл exosphere.bin, чтобы не было путаницы со свежими бинарниками.

- Раздел «Модули» / «Приложения»:
  - PPSSPP: добавлена корректная кнопка скачивания/установки (распаковка в корень).
  - Добавлен отдельный блок «Патчи от Dimasick-git».
  - Minecraft Online (мод): добавлена установка из GitHub релиза v1.0 с распаковкой в корень.
