# Архитектура каталога и установки v11.0.0

## Назначение

Ryazhenkabestcfw Tuner остаётся информационным пакетом: он не содержит разгона, профилей CPU/GPU/RAM, детекторов или автоматических OC-действий. В нём появляется отдельный каталог проверенных компонентов Ryazha для установки из официальных GitHub Releases.

## Структура меню

Основная страница содержит информацию о переносе тюнинга в Ryazha-clk с версии 3.0.0, безопасный экран системной информации и три точки входа в каталог: базовые компоненты, overlays и приложения. Каждый пункт каталога размещён в отдельном INI-файле внутри `include/`, чтобы список был легко поддерживать и обновлять без изменения основного информационного раздела.

## Правила установки

| Тип пакета | Действие |
|---|---|
| ZIP с корневой SD-структурой | Скачать во временную папку пакета, распаковать в `/`, удалить временный ZIP. |
| ZIP с внешней папкой | Скачать и распаковать во временную папку, скопировать только `switch/` и `config/` в соответствующие места на SD, очистить временные файлы. |
| OVL | Скачать напрямую в `/switch/.overlays/`. |
| NRO | Скачать напрямую в конкретную папку `/switch/<app>/`. |

Все установочные команды требуют удержания кнопки A. Для архива EdiZon выбран прямой `.ovl`, потому что ZIP содержит путь `../BUILD_INFO.txt`; такая структура не будет использоваться в автоматической распаковке.

## Контроль источников

Каждый пункт использует только один выбранный asset по URL `releases/latest/download/<asset>`. Файлы `.sha256`, дублирующие OVL/NRO и альтернативные ZIP не используются. Стабильные asset-имена и правила публикации зафиксированы в `RELEASE_ASSET_CONTRACT.md`.

## Ограничения

`RyazhaTune` добавлен как медиаплеер v5.5.0: в его ZIP входят sysmodule, overlay и конфигурация, которые распаковываются в корень SD. Он не является модулем `Ryazha-clk`; этот отдельный тюнинговый проект по-прежнему развивается отдельно. `Sys-clk` и другие OC-компоненты не добавляются: изменение частот и напряжений вынесено из тюнера полностью.
