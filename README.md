# Ryazhenkabestcfw Tuner

**Ryazhenkabestcfw Tuner** — русскоязычный пакет настроек и обслуживания для Nintendo Switch с Atmosphère CFW и Ryazhahand-Overlay. Он объединяет системные параметры, управление памятью и вентиляторами, установку полезных модулей и homebrew, обновление компонентов и точечное удаление установленных пакетов.

Проект сохраняет привычную структуру старого тюнера Ряженки, но развивается как самостоятельная система. Подробности конкретных выпусков находятся в [CHANGELOG](CHANGELOG.md), а актуальный архив — в разделе [Releases](https://github.com/Dimasick-git/Ryazhenkabestcfw-Tuner/releases).

> **Важно:** Ryazhenkabestcfw Tuner не является OC-тюнером CPU/GPU/RAM. Полный тюнинг и лимит зарядного тока относятся к отдельному оверлею **Ryazha-clk**. В самом пакете оставлены только отдельные параметры вентиляторов через Atmosphère.

## Возможности

| Раздел | Что делает |
|---|---|
| **Ряженка** | Открывает обновление тюнера, установку Ryazha-clk, вентиляторы, Atmo-Patch, 8 ГБ ОЗУ и системные параметры. |
| **Вентиляторы** | Предлагает готовые и ручные кривые для портативного и док-режима, коэффициенты датчиков для разных ревизий Switch и безопасный сброс к параметрам Atmosphère. |
| **Atmo-Patch** | Содержит адаптированный набор управления памятью: патч памяти и настройку буферов Ryazhahand. |
| **8 ГБ ОЗУ** | Устанавливает специальный payload для совместимых Mariko-консолей с физическими 8 ГБ памяти и сохраняет резервную копию исходного payload. |
| **ПО и утилиты** | Устанавливает homebrew, оверлеи, sysmodules, патчи и инструменты из проверенного каталога. |
| **Модули Ряженки** | Устанавливает и обновляет проекты экосистемы Ряженки через постоянные ссылки на GitHub Releases. |
| **Удаление** | Удаляет только файлы выбранного компонента и предоставляет отдельные сбросы настроек. |
| **Миграция** | При запуске пакета очищает подтверждённые остатки старых тюнеров Ultra, 4IFIR Wizard, NX-Venom и ранних версий Ряженки. |

## Как устроен тюнер

Главный пакет всегда находится в одной папке на SD-карте:

```text
switch/.packages/Ryazhenkabestcfw Tuner/
├── package.ini                 # Главное меню
├── boot_package.ini            # Миграционная очистка старых тюнеров
├── config.ini                  # Версия пакета и состояние 8 ГБ-патча
└── Data/
    ├── Atmo-Patch/             # Память и буферы Ryazhahand
    ├── Fan Control/            # Кривые и сброс вентиляторов
    ├── Ryazha-clk/             # Резервный экран будущего Ryazha-clk
    ├── System/8GB/             # Payload 8 ГБ-патча
    └── Updater/                # Загрузки, модули, обновление и удаление
```

Такой формат нужен для работы системы Packages в Ryazhahand. Не переносите внутренние папки отдельно и не распаковывайте ZIP в `switch/Ryazhenkabestcfw Tuner/`: архив следует распаковывать **в корень SD-карты**.

## Установка

Скачайте единственный архив `Ryazhenkabestcfw_Tuner.zip` со страницы [Releases](https://github.com/Dimasick-git/Ryazhenkabestcfw-Tuner/releases/latest), распакуйте его в корень SD-карты и откройте Ryazhahand-Overlay. Затем выберите **Ryazhenkabestcfw Tuner** в списке пакетов.

| Сценарий | Действие |
|---|---|
| Первая установка | Распакуйте ZIP в корень SD-карты. |
| Обновление тюнера | Откройте **Обновление → Обновить тюнер**. Пакет использует постоянный release-asset и сам очищает временный ZIP. |
| Установка компонента | Откройте **ПО и утилиты → Скачать** или **Модули** и выберите нужный пункт. |
| Удаление компонента | Откройте **ПО и утилиты → Удалить** и выберите конкретный компонент. |

Временные ZIP-загрузки тюнера хранятся в `/config/ryazhahand/downloads/Ryazhenka/` и удаляются после успешной распаковки. Прямые `.nro` и `.ovl` сразу сохраняются в конечные системные папки.

## Ryazha-clk и вентиляторы

**Ryazha-clk** — отдельный проект для полного тюнинга. Пункт **«Установить Ryazha-clk»** автоматически скачивает последний проверенный `Ryazha-clk.zip` из Releases. Устаревший Sys-clk (RU) в тюнер не входит и не показывается в меню.

Раздел **«Вентиляторы»** не разгоняет систему. Он изменяет только термальные параметры Atmosphère: таблицы скоростей вентилятора и коэффициенты температурных датчиков. Перед ручной настройкой сохраните рабочую конфигурацию SD-карты. Пункт **«Сброс к стоку»** удаляет внесённые тюнером параметры и возвращает стандартное поведение Atmosphère.

## Память и 8 ГБ ОЗУ

### Atmo-Patch

Раздел **Atmo-Patch** объединяет две независимые функции. Патч памяти изменяет выбранный INI-профиль загрузчика для совместимого ядра Mesosphere, а экран **«Буферы»** настраивает размеры буферов Ryazhahand в `/config/ryazhahand/config.ini`. Экран **«Просмотр INI»** показывает выбранный файл, а **«Восстановить штатное ядро»** удаляет только добавленную строку `kernel` из выбранного профиля. Эти настройки не заменяют и не требуют CPU/GPU/RAM-overclock.[1]

### Патч 8 ГБ

Пункт **«8 ГБ ОЗУ»** предназначен только для совместимых Mariko-консолей с физическими 8 ГБ памяти. Он использует payload из Ultra Tuner и перед заменой сохраняет исходный payload в резервной папке Ряженки.[2]

> **Не включайте 8 ГБ-патч на обычной Switch с 4 ГБ RAM.** Неподходящий payload может вызвать проблему загрузки. Если вы не уверены в ревизии устройства, оставьте параметр выключенным.

## Каталог программ и модулей

Каталог разделён на **Хоумбрю**, **Оверлеи**, **Патчи и другое**, а также проекты Ряженки. В нём есть, например, DBI, Sphaira, DuckStation, Moonlight, MemToolkitNX, EdiZon, FPSLocker, Fizeau, ReverseNX-RT, Mission-Control, PPSSPP, Mod Alchemist и sys-ftp.

Ресурсы, заимствованные из Ultra Resources, публикуются через зеркало [Ryazhenka-resore](https://github.com/Dimasick-git/Ryazhenka-resore). Его workflow сверяет выбранные assets upstream и обновляет стабильный release-asset зеркала. Прямые ссылки на проекты ppkantorski и другие внешние репозитории сохраняются там, где это требуется самому компоненту.[3]

## Удаление и миграционная очистка

Меню **«Удалить»** работает по точным путям: оно не удаляет весь `switch/`, общий hbmenu или сторонние файлы SaltySD. Для некоторых компонентов предусмотрены отдельные действия: например, патчи FPSLocker удаляются без удаления самого оверлея.

`boot_package.ini` выполняет идемпотентную миграционную очистку при запуске пакета. Она удаляет только известные остатки старых тюнеров, в том числе каталоги Ultra Tuner, 4IFIR Wizard, NX-Venom и устаревшие внутренние папки ранних версий Ряженки. Общие файлы Ryazhahand, Alchemist, AIO Switch Updater и актуальные папки этого пакета сохраняются.

> Если вы снова установите один из перечисленных старых тюнеров при активной Ряженке, его подтверждённые служебные папки будут очищены при следующем запуске Ryazhenkabestcfw Tuner.

## Системные параметры

В пакете доступны нетюнинговые параметры Atmosphère и консоли: GPU Scheduler, USB 3.0, авто-перезагрузка, настройки видеозахвата, FPS и битрейт. Изменяйте системные параметры по одному и перезагружайте консоль, если это указано на экране.

## Безопасность

Перед экспериментами с памятью, вентилятором, payload или системными параметрами сделайте резервную копию SD-карты. Тюнер проверяет пути и использует резервные копии там, где это предусмотрено функцией, но не заменяет полноценный бэкап пользовательских данных.
