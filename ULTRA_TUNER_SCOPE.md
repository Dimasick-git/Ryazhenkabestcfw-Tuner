# Перенос Ultra Tuner в Ryazhenkabestcfw Tuner v11.0.0 — вариант A

## Решение

Переносится только безопасная нетюнинговая часть интерфейса Ultra Tuner: структурированный каталог, экран системной информации, единые правила скачивания, распаковки и очистки временных файлов, а также разделение компонентов на базовые, overlays и приложения. Тюнер остаётся без изменения частот, напряжений, таймингов памяти, fan-curve, OC-патчей, перезагрузок и автоматических системных действий.

## Что будет добавлено или улучшено

| Источник Ultra Tuner | Как применяется в Ryazhenkabestcfw Tuner |
|---|---|
| Вкладка `Info` | Новый безопасный экран с текущими данными Atmosphère, Horizon OS, IP-адресом, RAM vendor/model и версией пакета. |
| Вкладка `Software` | Основа для разделённого каталога базовых компонентов, overlays и приложений. В каталог попадают только утверждённые проекты Dimasick-git. |
| Единый download/unzip-поток | Временная загрузка, распаковка, удаление ZIP и уведомление о результате. |
| Установка из latest release | Переход на `releases/latest/download/<стабильное-имя>` после стандартизации asset-имён в выбранных репозиториях. |
| Понятная навигация | Разделы «Информация», «Каталог», «Помощь»; каждая установка требует удержания A. |

## Компоненты Ultra Tuner, которые не будут добавлены

| Компонент или проект | Причина исключения |
|---|---|
| Horizon-OC и его `dist.zip` | Разгон и патчи ядра; исключён вариантом A. |
| sys-clk, RAM OC, CPU/GPU undervolt, vMin, SoC tables | Все функции меняют частоты, напряжения, таблицы DVFS или тайминги памяти. |
| Presets Manager, Backup Manager, Autobackup | Управляют OC-профилями и резервными копиями настроек разгона. |
| `Data/Tuner/*`, `Data/Presets/*` | CPU/GPU/RAM/SoC-конфигурации, JSON-пресеты и скрипты тюнинга. |
| `Data/Updater/Curves*` и NX-FanControl | Управление кривыми вентиляторов; не относится к безопасному каталогу. |
| Ultra Tuner Updater | Обновляет upstream Ultra Tuner и может применять Horizon-OC-компоненты. |
| UltraCam для BotW/EoW/TotK | Игровые моды и внешние ресурсы Ultra-NX; не входят в каталог проектов пользователя. |
| DBI | Ultra Tuner меняет настройки DBI и добавляет внешний индекс источников; не будет менять пользовательскую конфигурацию. |
| Linkalho | Внешний homebrew, не выбранный пользователем. |
| DuckStation и загрузка BIOS | Внешний проект; пакет Ultra Tuner загружает сторонний BIOS-архив, поэтому не включается. |
| Moonlight, ThemezerNX, SwitchThemeInjector | Сторонние приложения и темы, не утверждённые пользователем. |
| Battery Desync Fix, Benchmark Toolbox, MemToolkitNX, MicroMemBench | Внешние системные и memory-инструменты; часть связана с диагностикой и настройками памяти. |
| Оригинальные Status Monitor, Fizeau, sys-tune | Уже заменены утверждёнными проектами Ryazha или RyazhaTune. |
| Tetris, MasterVolume, BT Audio, sys-dock | Внешние overlays, не выбранные пользователем. |
| FPSLocker Warehouse patches, DVR patches | Сторонние патчи и модификации, не выбранные пользователем. |
| Mod Alchemist | Внешний менеджер модов, не выбранный пользователем. |
| sys-ftp | Ultra Tuner включает анонимный вход `Login anon 1`; не добавляется из соображений безопасности. |
| Массовое удаление homebrew, overlays и скриптов | Деструктивные действия не войдут в пакет. |

## Уточнение названий

`RyazhaTune` — медиаплеер и фоновый аудио sysmodule. Он добавлен в каталог приложений как отдельный проект. Упоминание будущего тюнингового проекта исправляется на **Ryazha-clk**; его репозиторий и функции не будут добавляться до отдельного утверждения.

## Источники

Анализ выполнен на основе распакованного пакета Ultra Tuner 23|R5⁴ и его `Data/Updater/Software.ini`, `Data/Tuner/*`, `Data/Presets/*` и меню `package.ini`.
