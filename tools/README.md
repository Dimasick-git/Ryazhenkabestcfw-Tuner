Патчи памяти для Atmosphere 1.12 / HOS 23 взяты из Ultra Tuner 23-R7:
https://github.com/Ultra-NX/Ultra-Tuner/releases/tag/23-R7

Варианты +1,85 МБ и +40 МБ сохраняют настройки памяти исходных ядер.
Поверх них перенесены исправления ABI Ряженки: отключена запись времени CPU
в TLS +0x108; запись дескриптора нового потока в TLS +0x110 пропускается
только для создателя с libnx ThreadVars. Инициализация главного потока сохранена.
Проверки выполняют настоящий ARM64 код в Unicorn для SDK, libnx и пустого TLS.
Проверка в эмуляторе не заменяет проверку игры на консоли.

Воспроизведение: установить Python-пакет unicorn, затем выполнить
`python tools/update_memory_kernels.py "путь/Ultra Tuner/Data/Updater"`.
Скрипт принимает только два закреплённых SHA-256 upstream.
Проверка готовых файлов: `python tools/update_memory_kernels.py --verify`.
`legacy_tls_guard.bin` собирается из соседнего `.s` через AArch64 as/objcopy.

Применение — через меню «Патч памяти» с выбором INI загрузчика.
Для +40 МБ веб-браузер и использующие его игры могут перестать работать.
Восстановление штатного ядра доступно в том же меню. Требуется перезагрузка.
