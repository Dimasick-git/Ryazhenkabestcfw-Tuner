# Changelog

Все заметные изменения проекта.

## v11.0.0 — 2026-08-17

Версия переработана в **информационный пакет**. В интерфейс добавлено сообщение о том, что весь тюнинг перенесён в **Ryazha-clk** начиная с версии **3.0.0**.

Из пакета удалены меню и данные CPU/GPU/RAM, пресеты, Memory Kit, патчи памяти и Atmosphere, кривые вентиляторов, OC-бэкапы, KIP-детекторы, Updater, системные переключатели, настройки видеозахвата и зарядки. Загрузочный и выходной сценарии нейтрализованы: v11.0.0 не читает, не применяет и не изменяет настройки тюнинга.

Детектор и дальнейшая логика тюнинга будут поддерживаться отдельно в новом проекте.

В информационный пакет добавлен каталог проверенных компонентов Ryazha. Он устанавливает один выбранный asset из официального GitHub Release для каждого пункта: архивы с корневой SD-структурой распаковываются в `/`, архивы с внешней папкой обрабатываются во временной директории, а `.ovl` и `.nro` устанавливаются напрямую в целевые пути. Временные ZIP-файлы удаляются после успешной установки.

В каталог добавлены Ryazhahand Overlay, Mission-Control, Ryazhenka AIO Updater, ovlSysmodules, Ryazha Status Monitor, EdiZon, ReverseNX-RT, Fizeau, FPSLocker, RyazhaAI, RyazhaTune, SwitchWave и PPSSPP. RyazhaTune добавлен как медиаплеер v5.5.0 с фоновым sysmodule, overlay и конфигурацией; после его установки нужна перезагрузка Switch. Ссылки каталога используют `releases/latest/download/<asset>` и автоматически получают новый пакет после публикации release со стабильным именем asset. Проекты разгона по-прежнему намеренно не включены.

## Исторические версии

До v11.0.0 проект содержал форк тюнинговых конфигураций для Nintendo Switch. Эти компоненты в информационную версию не входят.
